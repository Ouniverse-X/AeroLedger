# Application Package

- [SHA256SUMS](SHA256SUMS)

最低支持 Android 8.0 / API 26，版本 1.0.1（versionCode 2）。本版包含离线图片记账、多单核对、原图预览和主动授权截屏。安装时按系统提示允许当前来源安装应用；无需 Android Studio 或测试账号。

保留原 v1.0 安装包作为历史版本。v1.0.1 与原 v1.0 课程包签名一致，可以覆盖更新；更新前建议导出 CSV。它不是本地 v1.2.7 的升级包。

APK 为开发机 debug 签名的压缩 release 构建，用于课程演示。每个成员的数据独立保存在各自手机；目前不提供跨设备同步。缴费提醒需要各自允许系统通知，精确提醒授权可选。

可复现构建与后续开发方式见 [DEVELOPMENT.md](../DEVELOPMENT.md)。
